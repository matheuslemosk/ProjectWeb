# Mural de Achados e Perdidos

## Tema
Mural de Achados e Perdidos: consulta pública aos itens reportados. Área autenticada
para cadastramento de novos objetos e alteração de status de devolução.

## Equipe
- Matheus (individual)

## Tecnologias
- Node.js
- Express
- EJS
- MySQL

## Estrutura
```
achados-perdidos/
├── app.js
├── config/db.js
├── controllers/itemController.js
├── models/itemModel.js
├── routes/publicRoutes.js
├── views/ (home, detalhes, sobre, 404, partials)
├── public/css/style.css
└── database.sql
```
